# Scoring: how a spin resolves

Every spin resolves in a fixed order. The player can see the order and rearrange it.

1. The wedge the spin lands on.
2. The other wheels, left to right.
3. Always-on items, in the order the player arranged them.

The player arranges the wheels and the items, so building a payout is a skill. Putting additive bonuses ahead of multipliers, for example, can multiply a score: in Balatro, rearranging jokers that way doubled one example hand (`docs/research/01-design-foundations.md` §1).

The game shows a payout step by step in the same order, so the player can see how each piece of their build contributed.
